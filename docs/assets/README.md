# Assets and attribution

- `pocket-gimbal-adjustment.png` — diagram provided by the project owner from RadioMaster Pocket reference material. It is included here for educational use in the guide; see the [RadioMaster Pocket M2 product page](https://radiomasterrc.com/products/pocket-radio-controller-m2) and [official manuals index](https://radiomasterrc.com/pages/user-manuals) for current manufacturer information.
- `pocket-control-map.svg` — original simplified vector schematic prepared for this project. It is illustrative, not a dimensionally accurate drawing or a substitute for the current product manual. Switch functions are user-configurable in EdgeTX.

When publishing these files to GitHub, retain the manufacturer's link and the warning that model settings can differ by firmware version.
