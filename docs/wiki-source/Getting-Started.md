## First session checklist

- [ ] Install batteries matching the Pocket manual and inspect polarity/condition.
- [ ] Install the radio antenna before powering the radio with the internal RF module enabled.
- [ ] Connect USB-C using a data-capable cable.
- [ ] If EdgeTX offers USB modes, choose the joystick/game-controller option for simulator use.
- [ ] In Liftoff, calibrate and confirm roll, pitch, yaw and throttle one at a time.
- [ ] Confirm throttle minimum and axis direction.
- [ ] Fly one easy drill for 5–10 minutes.
- [ ] Log one win, one difficulty, and one next focus.

## What counts as progress?

Not just speed. Progress includes smoother control, fewer over-corrections, more clean gates, a deliberate landing, better orientation recovery, and the ability to explain why a setup works. If the drill is too hard, reduce speed/difficulty rather than rushing to Acro freestyle.
