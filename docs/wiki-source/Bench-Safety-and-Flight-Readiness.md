# Bench Safety and Flight Readiness

**All setup, USB configuration, motor testing and bench troubleshooting must be done with every propeller removed.** A quad can start motors unexpectedly if armed or configured incorrectly.

## Propeller-off bench checklist

- [ ] All propellers removed; keep them away from the workspace.
- [ ] Battery disconnected before wiring changes or soldering.
- [ ] No visible shorts, solder bridges, frayed wires, pinched insulation or loose hardware.
- [ ] Battery polarity, voltage range, regulator outputs and connector wiring match the exact hardware documentation.
- [ ] Correct flight-controller firmware target and board orientation selected.
- [ ] Radio/receiver firmware and configuration are compatible; binding/link is confirmed.
- [ ] Receiver channel mapping matches intended roll, pitch, yaw and throttle directions.
- [ ] Arm and disarm controls are deliberate and verified.
- [ ] Failsafe has been configured and checked according to the exact firmware's procedure.
- [ ] Motor numbering/output mapping and direction match the flight-controller diagram.
- [ ] Gyro/FC orientation responds correctly when the frame is moved by hand.
- [ ] Video link operates as expected; VTX antenna is connected and mounted before powering the VTX.
- [ ] No unexpected heat, smell, smoke, resets or abnormal current draw.
- [ ] Known-good configuration is backed up and versions recorded.
- [ ] Experienced builder/pilot has reviewed the setup.

Any uncertainty means stop and resolve it before installing props.

## Outdoor flight-day gate

- [ ] Current airspace, location, aircraft and radio requirements checked from official sources.
- [ ] Site is appropriate and clear of bystanders, roads, animals, buildings and other aircraft.
- [ ] Weather, visibility and wind are appropriate for the aircraft and pilot.
- [ ] Aircraft inspected; fasteners, props, motors, antenna mounts and wires are secure.
- [ ] Correct model selected; control link, video link, battery and telemetry warnings checked.
- [ ] Arming/disarming and failsafe were previously verified with props removed.
- [ ] A safe landing area and conservative first-flight plan are selected.
- [ ] Beginner's first flights are supervised by an experienced pilot where practical.

## Battery handling

- [ ] Pack inspected for impact, puffing, puncture, damaged leads or unusual heat.
- [ ] Charger setting matches battery chemistry and cell count.
- [ ] Charging is attended in an appropriate, fire-conscious area away from combustible materials.
- [ ] Damaged or suspicious packs are not charged or flown.
- [ ] Battery disconnected before handling aircraft after a crash.

## Post-flight

- [ ] Disconnect battery and inspect the aircraft.
- [ ] Check props, frame, motors, solder joints, connectors and antenna mounts.
- [ ] Record damage and any configuration changes.
- [ ] Run relevant propeller-off checks after repairs.
