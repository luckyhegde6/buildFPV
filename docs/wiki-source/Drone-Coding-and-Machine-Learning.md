# Drone Coding and Machine Learning Learning Path

This is an **optional advanced track**, not a prerequisite for learning manual FPV control. Start here after you are comfortable with basic drone systems and have established regular simulator practice. Use the simulator and desktop coding projects before experimenting with physical aircraft.

## Suggested project ladder

1. Run a supplied example without modifying it.
2. Make a small change to movement or timing and explain the effect.
3. Log commands, state and errors; make the script fail safely when a connection or command fails.
4. Try image capture and basic computer-vision processing only in the simulator or the supported educational drone environment.
5. Read the target platform's API limits, emergency-stop behavior, battery requirements and operating rules before any physical test.

## Safety and scope

- This track is for software learning and is not a guide to bypassing geofencing, operating restrictions, identification systems, or safety controls.
- Do not use a coding demo as proof that a real FPV aircraft supports the same API or autonomous behavior.
- Keep props off during bench setup, testing and configuration. Prefer the simulator for early code experiments.
- Any real flight must follow current official rules, the exact platform's manual, site permissions and safe operating procedures.
