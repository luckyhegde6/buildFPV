## Walkthrough checkpoints

- [ ] Identify the radio's exact RF version before following RF or binding steps.
- [ ] Install/fold out the antenna correctly before using internal RF.
- [ ] Learn the button navigation: SYS, MDL, RTN, PAGE, TELE and menu wheel.
- [ ] Confirm current model name before configuration.
- [ ] Create `SIM-Liftoff` separately from a future `QUAD-ELRS` model.
- [ ] For a USB simulator setup, select USB Joystick when prompted; begin with Classic mode.
- [ ] For USB joystick use, follow EdgeTX documentation regarding internal/external RF being turned off.
- [ ] For a real quad, check ExpressLRS TX/RX versions and hardware targets before update/bind.
- [ ] Save the radio and Betaflight configuration before customising.
- [ ] Record the outcome and one next action in [[Learning Journal]].

## Safety note

A simulator walkthrough is for radio input, not real-aircraft readiness. For real hardware, remove propellers before bench setup/motor testing, use the exact receiver/FC manuals, and verify ARM, disarm and failsafe before flight.
