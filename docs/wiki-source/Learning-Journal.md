## 📸 Keeping simulator evidence

If you capture a screenshot or replay:

1. Add the date and track to the filename, e.g. `2026-10-17-liftoff-trackname.png`.
2. Attach the image to a GitHub issue or store a reasonably sized image under a dated `media` directory.
3. Note the track, game settings, quad preset, rates if changed, and lap time.
4. If comparing race times, compare the **same track and settings**. A faster time can result from a different setup, track condition, or shortcut—not only better stick control.
5. Avoid committing full-size video files to normal Git history; link an external video or compress clips.

## 📈 Optional progress scorecard

Rate each 1–5 once a week. The number is your self-check, not an objective flight score.

| Skill | 1 = early stage | 5 = dependable |
|---|---|---|
| Throttle smoothness | Big jumps / hard to manage | Smooth and deliberate |
| Turning both directions | Often loses orientation | Turns consistently both ways |
| Line choice | Reacts late | Looks ahead through gates/corners |
| Recovery | Panics / resets | Calmly regains control |
| Landing | Unplanned | Controlled approach and settle |
| Reflection | No log | Clear win, issue and next focus |

## 🔁 Restart after a missed day

Do not compensate with an exhausting marathon. Pick **5 minutes**, complete one drill, and log it. The habit is returning—not maintaining a perfect streak.
