# 📓 Learning log — make progress visible

The journal exists to turn practice into a habit and experiments into reusable knowledge. Keep each entry short enough that you will actually write it.

## Daily loop (2 minutes to log)

1. Choose a realistic duration: **5 / 10 / 15 / 20 / 30+ minutes**. Even five intentional minutes count.
2. Pick one skill objective before launching Liftoff.
3. Practise with the radio that is actually selected and noted in the log.
4. If you raced, record the track, mode, and best lap time; do not compare times from different tracks or conditions as if they were equivalent.
5. If you captured a screenshot or video, attach it to the GitHub issue or add a relative link to the file.
6. Write one win, one difficulty, and one next-session focus.

## Recommended log methods

- **Lowest friction:** create a GitHub Issue with the `Daily Liftoff Session` template. Issues can hold images, notes, and links without cluttering the source code.
- **Markdown in the repo:** copy [`templates/daily-session.md`](templates/daily-session.md), name it `YYYY-MM-DD.md`, and put it under a folder such as `docs/learning-log/sessions/2026/10/`.
- **Configuration experiments:** copy [`templates/config-change.md`](templates/config-change.md). Record the before/after state and a way to roll back.

Keep simulator screenshots in a sensible folder if you want versioned images, e.g. `docs/learning-log/media/2026/10/`. Compress large videos and prefer linking to a video host; do not commit huge recordings by accident.

## Weekly review (5–10 minutes)

- [ ] How many days did I practise, and what was the most repeatable session length?
- [ ] Which control input is smoother now? What still causes over-correction?
- [ ] Did I improve a track time on the **same track and settings**? Save the result/screenshot.
- [ ] What one topic did I learn: ELRS, receiver mapping, batteries, Betaflight, video, or repair?
- [ ] What should I repeat next week? Pick one, not ten.
- [ ] Any configuration changes or safety questions still unresolved?

## Milestones are skills, not calendar dates

- [ ] I can identify roll, pitch, yaw and throttle by moving one stick axis at a time.
- [ ] I can fly a calm lap without panic corrections.
- [ ] I can recover orientation after turning around.
- [ ] I can complete a circuit and land intentionally.
- [ ] I understand the control-link path separately from the video-link path.
- [ ] I can explain why props must be removed for bench work.
- [ ] I know where to find the official Betaflight and ExpressLRS documentation.
